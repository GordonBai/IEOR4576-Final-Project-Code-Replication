# Notebooks

These notebooks are inspection surfaces, not the source of reported results.

- `01_replication_validation.ipynb`: Stage A input, feature and causality QA.
- `02_graph_backtest_validation.ipynb`: saved graph and walk-forward results.
- `03_complete_paper_results.ipynb`: saved tables and figures.
- `archive/00_data_preprocessing_legacy.ipynb`: historical data-construction
  provenance. It predates the current `data/raw`, `data/interim` and
  `data/processed` layout and is intentionally excluded from `make all`.

Install the package from the repository root before opening the active
notebooks: `make install`.
